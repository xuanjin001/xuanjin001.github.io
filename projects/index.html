These are the things I’ve actually been building. Not side-project ideas I haven’t touched — things that are running, being used, and still being improved.

🤖 Gideon — Personal AI Assistant on OpenClaw Link to heading

My personal AI assistant, built on top of OpenClaw and running on a self-hosted server. Gideon handles my to-do list, daily news briefings, email triage, health tracking nudges, and a growing set of custom automations I’ve built over the past several months.

The interesting part isn’t the AI — it’s the system design. I’ve built out memory curation, session search, skill packaging, and guardrails so Gideon doesn’t just “run with it” and make a mess. Learned a lot the hard way (see: the to-do list disaster).

Stack: OpenClaw · Python · DuckDB · Linux VPS · custom skills

🧾 ETL App with AI — Personal Receipt Tracker Link to heading

An AI-powered personal finance app that takes receipts (photo, file upload, paste, or manual entry) and uses an LLM to extract and structure every line item automatically. The goal: one place to see exactly where my money is going, without manually entering anything.

Under the hood it’s a full ETL pipeline — extract from receipt images, transform via LLM, load into a structured database — with charts and search on top. Still adding to it.

Stack: Python · LLM extraction · DuckDB · full-stack web app · Costco purchase history API
